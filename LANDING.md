# Landing brief

## Goal of this mock

Composición visual para **mostrar y cerrar un sí**: que se sienta profesional, urgente-útil y local. No hace falta que el contenido operativo esté 100% confirmado; sí hace falta que se vea creíble.

## Headline (definido)

**Venta y carga de baterías, las 24 hs.**

## Site map (secciones)

1. **Ticker** (global)
2. **Inicio (hero)** — marca, promesa, CTAs
3. **Servicios** — venta, carga, (domicilio / instalación / marcas si entran)
4. **Cómo funciona** — 3 pasos (la “+1” útil para urgencia)
5. **Nosotros** — local, confianza, CABA
6. **Reseñas** — Google
7. **Contacto** — teléfono, WhatsApp, dirección, mapa
8. **Footer** — links + datos

Nav sugerida: Inicio · Servicios · Nosotros · Reseñas · Contacto

## Hero — 3 direcciones para elegir

### H1 — Urgencia full-bleed
Foto de taller/auto a sangre, overlay oscuro, headline **“Venta y carga de baterías, las 24 hs.”** (definido), **Llamar** enorme + WhatsApp al lado, trust “4.9 Google · 24 hs”.  
*Inspo tip:* landings de emergencia (electricistas / roadside) — CTA de llamada dominante, mobile-first.

### H2 — Split local
Izquierda: marca + copy + CTAs. Derecha: foto del mostrador / fachada (placeholder). Más “comercio de barrio”, menos emergencia.  
*Inspo tip:* oil-change / garage editoriales split.

### H3 — Tipográfico + confianza
Poco o nada de foto arriba: Syne display grande, ticker ya cuenta 24 hs, debajo estrellas Google + dos botones. Muy limpio para pitch de marca.  
*Inspo tip:* manifesto / trade-magazine heroes (type-led).

**Implementado:** **H1** (urgencia full-bleed) con identidad Fusión A.

## Servicios (placeholder set)

- Venta de baterías para auto  
- Carga de baterías  
- Asesoramiento / diagnóstico  
- Atención 24 hs  
- (Opcional visible): instalación / a domicilio — marcar como “consultar” si no está confirmado  

## Fotos: qué hacer ahora

Para **este mock de venta**: usar 3–5 fotos genéricas buenas (Unsplash/similar: taller, batería, calle CABA vibe) con caption discreto “imagen ilustrativa”.  
En paralelo pedir al cliente: fachada, mostrador, 1 trabajo, 1 detalle de batería, logo si tienen algo.

Así el mock brilla ya; el sitio final se vuelve “de ellos” cuando lleguen las reales.
