## Principios
1. One primary conversion per URL; secondary as link/outline.
2. Hierarchy: scanable H1→sections; whitespace; contrast.
3. Match system ↔ real world: language of VoC, not jargon.
4. Consistency: same primary button style everywhere.
5. Mobile-first for local: tap targets, click-to-call, no competing sticky junk.
6. Minimalist: remove competing offers/nav that dilute CTA.
7. Error prevention: clear hours/area/eligibility near CTA.
8. Craft skill = guardrails during build/edits, not a full redesign.

## Entra a la skill
Quick reference + red flags + “fix when editing” checklist. No autonomous redesign.
