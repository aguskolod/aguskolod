# Glosario — tipografía y expression (web)

Vocabulario mínimo para discovery → dirección visual. Condensado de práctica de brand/web; las skills amplían con fuentes en `research/`.

## Tipografía

| Término | Qué significa | Señal de marca típica |
|---|---|---|
| **Serif** | Remates en los trazos | Tradición, autoridad, editorial |
| **Sans geométrica** | Formas de círculo/línea | Moderna, técnica, limpia |
| **Sans humanista** | Proporciones más “escritas” | Cálida, cercana, humana |
| **Slab** | Serifs gruesos en bloque | Fuerza, oficio, impacto |
| **Display** | Para títulos grandes | Personalidad; no para body largo |
| **Body / workhorse** | Lectura corrida y UI | Legibilidad > carácter |
| **Pairing** | Display + body (máx. ~2 familias) | Contraste de categoría, armonía de mood |

**Proceso de elección:** adjetivos de marca (3–5) → categoría tipográfica → 2–3 candidatos → probar con copy real → chequear web (ñ, pesos, mobile, licencia).

## Expression rules (identidad en UI)

| Decisión | Por qué importa |
|---|---|
| **Radius** (botones/cards) | Suave/amigable vs. seco/técnico vs. angular/urgente |
| **Bordes / sombras** | Plano y honesto vs. elevado/premium |
| **Densidad** | Aire = calma/premium; compacto = utilidad/urgencia |
| **Motion** | Ninguno / sutil / presente — debe matchear la personalidad |
| **Imagen / assets** | Foto real local vs. stock vs. ilustración; temperatura de color |
| **CTA visual** | Un primario fuerte; secundarios quietos |

## Landings locales (estructura base)

Una oferta · una zona · un CTA. Flujo típico: hero → prueba/confianza → proceso → objeciones → contacto.
